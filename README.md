# 📊 Tableau Sales Performance Dashboard

An interactive **Business Intelligence (BI) dashboard** built using **Tableau** to analyze sales performance, customer behavior, product categories, and geographic distribution. This project transforms raw sales data into meaningful visual insights, enabling stakeholders to make informed business decisions.

---

## 📌 Project Overview

This dashboard provides a comprehensive view of sales performance through interactive visualizations and KPI reporting. It helps identify business trends, high-performing regions, profitable product categories, and customer purchasing patterns.

The dashboard is designed to support data-driven decision-making by allowing users to explore sales data across multiple dimensions, including time, location, customer segments, and product categories.
